# 页面视图与交互规范

## 1. 视图构成与职责划分

前端系统包含三个核心视图，覆盖参与者旅程与后台场控流程：

```text
┌─────────────────┐       登记昵称       ┌─────────────────┐
│  JoinView.vue   │ ───────────────────> │  PlayView.vue   │
│ (扫码登记与准入) │                      │ (答题与个人结算) │
└─────────────────┘                      └─────────────────┘

┌─────────────────┐
│  HostView.vue   │ (主持人现场调度、放音监控与全场控制)
└─────────────────┘
```

视图进入方式：
- `HostView.vue` 仅能通过直接输入网址 `/host` 进入，前端各页面均不设置指向该视图的跳转链接。
- `JoinView.vue` 与 `PlayView.vue` 面向参与者，页面内不提供主持人控制台入口。

顶部导航栏：
- 站点顶部品牌导航栏仅在参与者答题页 (`PlayView.vue`) 渲染，右侧「参与者」入口用于返回登记页。
- 登记页 (`JoinView.vue`) 不渲染站点顶部品牌导航栏，页面自主题标题直接开始。
- 主持人页面（登录页与控制台）不渲染站点顶部品牌导航栏，页面内不出现「参与者」标识。

## 2. 色彩体系与视觉阅读舒适度规范

系统采用以柔和丁香紫 `#C874D9` 为主色系的全局视觉体系。在保证鲜明品牌记忆点的同时，重点优化移动端小屏设备与现场光照环境下的阅读舒适度与视觉耐受度。

### 2.1 主色系与衍生阶元

主色阶元兼顾温润雅致的视觉质感与信息层级聚焦：
- **品牌视觉主色 (`--accent`)**：`#C874D9`。作为系统核心主色，应用于主题标题核心字眼强调、主操作实体按钮底色、选项选中边框高亮、得分核心数值以及控制台关键编号。该色彩明度与饱和度适中，呈现温和典雅的视觉感受，避免高纯度荧光色彩带来的刺眼感。
- **主色深阶 (`--accent-dark`)**：`#AC55BF`。用于按钮悬停与按压态、激活态链接、重点文字标签以及个人在排行榜中的高亮名次。在浅色背景下提供高于 4.6:1 的对比度，增强重要状态与关键文本的辨识清晰度。
- **主色柔和底衬 (`--accent-light`)**：`#FBF4FD`。用于单选项选中状态的背景填充、提示卡片淡色衬底。低饱和浅淡紫罗兰底色消除大面积深色填充造成的压迫感与视觉眩晕，长时间注视依然保持视觉放松。
- **轻量强调边框 (`--accent-line`)**：`#E5B5EE`。用于浅色卡片悬停边框与轻量徽标轮廓，勾勒清晰而柔和的视觉分界线。

### 2.2 舒适阅读与对比度规范

排版体系遵循 WCAG 2.1 AA/AAA 级无障碍可读性准则，消除因色彩对比生硬或对比度不足导致的视力疲劳：
- **文本对比度阶梯**：
  - **核心标题与正文文本 (`--ink`)**：采用深灰黑 `#171717`。在纯白背景下形成 16.1:1 的超高对比度，确保文字轮廓清晰锐利。避免使用极端纯黑 `#000000`，有效消除极端黑白对比引发的眩光。
  - **次级说明与辅助文本 (`--muted`)**：采用舒适中灰 `#595959`。在纯白背景下对比度保持在 7.0:1，完全满足 WCAG AAA 级（文本 ≥ 7:1）标准。层次分明的同时，保证辅助规则与说明文字字字清晰易读。
  - **三级辅助与时间戳文本**：采用柔灰 `#8C8C8C`，用于次要元数据与非关键辅助标记，对比度保持在 3.3:1 以上。
- **底衬与卡片呼吸感**：
  - 主页面背景底色采用纯净白 `#FFFFFF` 与柔灰白 `#FAFAFA`。
  - 卡片与面板采用纯白 `#FFFFFF`，边框采用浅柔灰 `#EAEAEA`，阴影使用超轻扩散弥散阴影（`0 18px 45px rgba(0, 0, 0, 0.045)`），杜绝厚重黑框与生硬暗影，营造舒缓呼吸空间。
- **排版比例与行高标准**：
  - **标题行高**：设置在 1.15 至 1.3 之间，辅以微紧字距（`-0.02em` ~ `-0.03em`），保持紧凑醒目的视觉张力。
  - **正文与说明行高**：保持在 1.6 至 1.75 之间，段落与表单字段间距保持充足留白（20px ~ 28px），确保多行文本在小屏设备上具备流畅舒适的换行阅读节奏。

### 2.3 语义状态色搭配规范

系统语义状态色与主色系 `#C874D9` 在明度与色相上保持平衡协调：
- **正确 / 成功状态 (`--green`)**：深翠绿 `#168267`，浅绿衬底 `#F1FBF8`。用于正确答案揭晓、已提交勾选与在线就绪指示。
- **错误 / 警示状态 (`--danger`)**：温润珊瑚红 `#C94A42`，浅粉衬底 `#FFF3F2`。用于答错选项标识与警示提示，警示明确且柔和不刺眼。
- **警告 / 观战过渡状态 (`--warning`)**：暖琥珀金 `#D48806`，浅金衬底 `#FFFBE6`。
- **倒计时动态渐变**：顶部 20 秒倒计时条采用深翠绿 `#168267`、经暖琥珀金 `#D48806`、至主色深阶 `#AC55BF` 的平滑色带，自然传递作答节奏，不给参与者施加极端压迫感。

## 3. 参与者登记页 (`JoinView.vue`) 交互设计

登记页仅保留主题标题区与入场表单区两个内容区块，区块之外的说明性元素均不渲染，表单内的基本必要说明文字全部保留：

1. **主题标题区**：
   - 活动主题标题（「旮旯原声之届不到的 BGM」）以海报式超大字体呈现：手机端标题实际渲染字号约为屏幕宽度的 20%（约 `20vw`），两行标题横向铺满屏幕，在手机端约占屏幕 50% 的视觉空间，作为页面的视觉主体。
   - 核心强调词（「BGM」）采用主色 `#C874D9` 着重渲染，形成明快舒适的视觉焦点。
   - 标题区上下不保留大面积留白，页面纵向空间由主题标题与入场表单区紧凑填满。
   - 登记页不渲染站点顶部品牌导航栏，页面自主题标题直接开始。
   - 标题下方不渲染玩法介绍段落，也不渲染「多人同步答题」「共 X 题」等元信息图标行。
2. **入场表单区**：
   - 保留「准备入场」引导词、「先给自己起个名字」表单标题与「最终排行榜会显示这个昵称。别害羞，名字越有记忆点越好。」昵称说明。说明文字使用 `#595959` 舒适中灰与 1.65 宽舒行高，杜绝文字拥挤。
   - 昵称输入框聚焦边框呈现主色 `#C874D9` 柔光态，提供明确的操作反馈。
   - 提供「进入活动」主按钮，采用主色 `#C874D9` 实体背景与白字，悬停和激活状态呈现深阶 `#AC55BF`；输入校验失败或连接异常时以温润警示条提示。
   - 表单下方保留「等待主持人开始后，所有人会同时进入答题」状态提示。

## 4. 参与者移动端 (`PlayView.vue`) 交互设计

针对户外高光、小屏手机使用场景深度优化：
1. **就绪等待状态**：
   - 顶部显示“等待主持人发题...”提示徽标。
   - 中心圆形等待指示图标呈现主色 `#C874D9` 细线勾勒。
   - 显示已登记的个人昵称与当前在线总人数。
2. **答题进行状态**：
   - **动态倒计时条**：顶部渲染 20 秒平滑渐变收缩动画条（翠绿 `#168267` -> 暖金 `#D48806` -> 深主色 `#AC55BF`），直观反映剩余作答窗口。紧急时刻倒计时数字以主色深阶高亮。
   - **曲目与难度标签**：标题上方以彩色标签渲染放音编号（如「音频 TRACK-01」）、题目类型（「氛围题」/「作品题」）与难度等级（「简单」/「中等」/「困难」）。
   - **单选操作卡片**：4 个大尺寸自适应按钮。未选中时采用细柔灰边框；参与者点击选项后，按钮边框立即高亮为主色 `#C874D9`，背景填充为舒适浅紫 `#FBF4FD`，左侧选项字母徽章填充为主色 `#C874D9` 与白字，锁定防止重复点击。
3. **答案揭晓状态**：
   - 倒计时归零后，系统自动标记选项结果：正确选项高亮为深翠绿 `#168267`（背景 `#F1FBF8`），若参与者选错则所选项高亮为温润珊瑚红 `#C94A42`（背景 `#FFF3F2`）。
   - 底部滑出半透明文本卡片，展示详细解析内容。
4. **结算排名状态**：
   - 最后一题结束后，页面自动展示“本轮挑战完成”结算卡片。
   - 突出显示个人最终得分，得分数字采用主色 `#C874D9` 呈现超大字号；展示累计作答总耗时（精确至小数点后一位，例如 `14.2 秒`）。
   - 下方展开本轮完整排行榜，标明各玩家的名次、昵称与答题用时；本人所在行以主色深阶 `#AC55BF` 高亮并加粗展示。

## 5. 主持人控制台 (`HostView.vue`) 交互设计

针对笔记本电脑宽屏控制台设计，信息呈模块化分区呈现：
1. **页头状态栏**：
   - 展示在线人数与当前活动状态徽标（如「等待开始」）。
   - 页头仅保留这两项信息，不渲染「自动轮转模式」标签，也不渲染「退出」按钮。
2. **顶部流程与模式控制栏**：
   - 提供「一键开始轮转」、「暂停自动轮转」、「恢复轮转」、「重置活动」等主操作按钮，主按钮采用主色 `#C874D9`。
   - 提供自动模式切换开关，支持随时在全自动与纯手动调度间无缝切换。
3. **放音协同指示看板**：
   - 屏幕中央显眼位置使用超大字号展示当前放音编号（例如 `当前放音：TRACK-03`），放音代号使用主色 `#C874D9` 高亮呈现，保障远距离与快速瞥视时的清晰辨识。
   - 同步标明建议播放区间（15~25 秒）与作品提示，便于场地放音人员瞥视确认。
4. **现场作答进度监控墙**：
   - 实时罗列当前房间所有在线玩家卡片。
   - 参与者完成提交后，对应卡片立即标记深翠绿勾选图标，并实时统计“已作答人数 / 在线总人数”。
5. **结算榜单与去重导出**：
   - 活动结束后自动渲染本轮排名表格。排行榜头名榜首徽章使用主色 `#C874D9` 实体填充，第二名与第三名分别使用渐变协调色阶。
   - 提供下载或在线查看 `leaderboard_summary.txt` 按钮，按钮以主色 `#C874D9` 文本高亮，便于核对全场总榜与去重奖品榜。

## 6. 界面设计与文案规范

- 界面尽可能减少非必要元素，各页面仅保留最简要的必要文字说明；基本必要的操作与状态说明文字全部保留。
- 页面排版避免大面积留白，内容以实际渲染字号紧凑呈现，不通过放大占位区域替代字号。
- 界面文案统一使用中文，各页面不出现英文装饰性小字（标题上方的大写英文眉题）。
- 版式层次通过中文标题、正文与间距呈现，不使用英文小字作为视觉点缀。
- 放音代号（如 `TRACK-01`）属于数据编号，与现场音箱播放列表文件名严格对应，界面中以「音频：TRACK-01」「当前放音：TRACK-01」等中文标签承载。
