# 页面视图与交互规范

## 1. 视图构成与职责划分

前端系统包含三个核心视图，覆盖参与者旅程与后台场控流程：

```text
┌─────────────────┐       登记昵称       ┌─────────────────┐
│  JoinView.vue   │ ───────────────────> │  PlayView.vue   │
│ (扫码登记与准入) │                      │ (答题与个人结算) │
└─────────────────┘                      └─────────────────┘

┌─────────────────┐
│  HostView.vue   │ (轮次切换、音频播放、时间轴调度与全场控制)
└─────────────────┘
```

视图进入方式：
- `HostView.vue` 仅能通过直接输入网址 `/host` 进入，前端各页面均不设置指向该视图的跳转链接。
- `JoinView.vue` 与 `PlayView.vue` 面向参与者，页面内不提供主持人控制台入口。

## 2. 参与者登记页 (`JoinView.vue`) 交互设计

登记页仅保留两个内容区块，其余说明性元素均不渲染：

1. **主题标题区**：
   - 活动主题标题（「旮旯原声之届不到的 BGM」）以超大字号呈现，作为页面的视觉主体。
   - 标题下方不渲染玩法介绍段落，也不渲染「多人同步答题」「共 X 题」等元信息图标行。
2. **入场表单区**：
   - 提供昵称输入框与「进入活动」主按钮，输入校验失败或连接异常时以警示条提示。
   - 轮次结束后参与者由答题页返回本页时，昵称输入框自动回填本地保存的内容，无需重复输入。

## 3. 参与者移动端 (`PlayView.vue`) 交互设计

针对户外高光、小屏手机使用场景深度优化：
1. **就绪等待状态**：
   - 顶部显示“等待主持人发题...”提示徽标。
   - 显示已登记的个人昵称与当前在线总人数。
2. **答题进行状态**：
   - **音频剩余时间条**：顶部渲染渐变收缩动画条，反映本题音频段剩余时间；进度与数值基于 `questionAudioStartEpochMs` 与 `questionAudioEndEpochMs` 计算，时间轴暂停时同步冻结。
   - **题型与难度标签**：标题上方以彩色标签渲染题目类型（「氛围题」/「作品题」）与难度等级（「简单」/「中等」/「困难」）。
   - **单选操作卡片**：4 个大尺寸自适应按钮。参与者点击选项后，按钮立即进入锁定状态并高亮边框，防止重复点击。
3. **已锁卷状态**：
   - 作答通道关闭后，界面标记“答题已结束”，选项保持只读，等待主持人揭晓。
4. **答案揭晓状态**：
   - 揭晓后系统标记选项结果：正确选项高亮为翠绿色，若参与者选错则所选项高亮为红色。
   - 底部滑出半透明文本卡片，展示详细解析内容；揭晓画面保持到下一题上屏。
5. **结算排名状态**：
   - `FINISH` 结算后，页面自动展示“本轮挑战完成”结算卡片。
   - 突出显示个人最终得分、累计作答总耗时（精确至小数点后一位，例如 `14.2 秒`）。
   - 下方展开本轮完整排行榜，标明各玩家的名次、昵称与答题用时。
   - 提供返回登记页入口；轮次结束标记到达后页面回到登记页，昵称自动回填。

## 4. 主持人控制台 (`HostView.vue`) 交互设计

针对笔记本电脑宽屏控制台设计，信息呈模块化分区呈现：
1. **顶部流程与模式控制栏**：
   - 提供轮次选择器与「开始播放」「暂停」「恢复」「重置活动」等主操作按钮。
   - 「开始播放」将音频定位到当前轮次开始标记并播放，同时建立本轮时间轴零点。
2. **音频与时间轴看板**：
   - 展示当前轮次名称、音频播放进度与「时间轴运行中 / 已暂停 / 已结束」状态。
   - 到达轮次结束标记时自动暂停并提示切换轮次或重置。
3. **现场作答进度监控墙**：
   - 实时罗列当前房间所有在线玩家卡片。
   - 参与者完成提交后，对应卡片立即标记绿色勾选图标，并实时统计“已作答人数 / 在线总人数”。
4. **手动兜底控制**：
   - 提供「锁卷」「揭晓答案」「下一题」按钮，用于在时间轴之外实施快速推进。
5. **结算榜单与去重导出**：
   - 活动结束后自动渲染本轮排名表格。
   - 提供下载或在线查看 `leaderboard_summary.txt` 按钮，便于核对全场总榜与去重奖品榜。

## 5. 界面设计与文案规范

- 界面尽可能减少非必要元素，各页面仅保留最简要的必要文字说明。
- 界面文案统一使用中文，各页面不出现英文装饰性小字（标题上方的大写英文眉题）。
- 版式层次通过中文标题、正文与间距呈现，不使用英文小字作为视觉点缀。
