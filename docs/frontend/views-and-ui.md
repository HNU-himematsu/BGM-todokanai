# 页面视图与交互规范

## 1. 视图构成

系统包含三个路由视图与五个参与面板：

```text
JoinView.vue
  ├── 线上登记页（/online 或 mode=online，缺省）
  └── 线下登记页（/offline 或 mode=offline）

PlayView.vue
  ├── OnlinePlayPanel.vue
  │     ├── OnlineProgress.vue
  │     └── OnlineResultPanel.vue
  └── OfflinePlayPanel.vue

HostView.vue
  ├── 主持人登录
  ├── 线下轮次与音频控制
  └── LeaderboardPanel.vue（本轮榜 / 线上榜 / 总榜）
```

进入方式：

- 网页根地址 `/` 进入线上登记页。
- 线下二维码使用 `/?mode=offline`；`/offline?event=jisong` 为等效入口，供既有二维码与手工输入使用。
- 显式线上地址使用 `/online?event=jisong`；`/?mode=online&event=jisong` 为等效入口。
- 主持人控制台只通过 `/host` 进入，参与者页面不提供控制台跳转。

## 2. 视觉体系

### 2.1 品牌主色

品牌主色为亮兰紫 `rgb(188, 74, 216)`（`#BC4AD8`），定义在 `src/theme.js`。全局色阶由主色派生：

| 令牌 | 渲染值 | 用途 |
| :--- | :--- | :--- |
| `--accent` | `#BC4AD8` | 主按钮、当前进度、选中边框、核心分数。 |
| `--accent-dark` | `#8D38A2` | 悬停、按压、重点链接。 |
| `--accent-mid` | `#D691E9` | 第二名徽章。 |
| `--accent-line` | `#EDCCF6` | 第三名徽章、轻边框。 |
| `--accent-light` | `#FCF5FD` | 选项选中底、提示卡片。 |

主按钮使用 `--accent` 实体底和纯白文字；悬停与按压切换为 `--accent-dark`。禁用态保留实体底与纯白文字，不使用低对比度灰字。

### 2.2 中性色与语义色

| 令牌 | 色值 | 用途 |
| :--- | :--- | :--- |
| `--ink` | `#171717` | 标题与正文。 |
| `--muted` | `#595959` | 辅助说明。 |
| `--line` | `#E9E9E9` | 分割线与边框。 |
| `--soft` | `#F7F7F8` | 轻量容器底衬。 |
| `--green` | `#168267` | 线下正确答案、成功状态。 |
| `--green-soft` | `#F1FBF8` | 正确答案浅底。 |
| `--danger` | `#C94A42` | 错误、警示、线下错选。 |
| `--danger-soft` | `#FFF3F2` | 错误浅底。 |
| `--warning` | `#D48806` | 时间不足与现场提醒。 |
| `--warning-soft` | `#FFFBE6` | 警告浅底。 |

线上模式不使用绿色正确/红色错误反馈表示题目结果。正确与错误语义色只用于线下揭晓、表单校验、网络错误和系统状态。

### 2.3 排版与阅读

- 标题行高 1.15 至 1.3，字距 `-0.02em` 至 `-0.03em`。
- 正文与说明行高 1.6 至 1.75。
- 核心文字使用 `--ink`，辅助文字使用 `--muted`。
- 卡片使用白色底、浅边框与低透明度阴影。
- 页面背景使用白色与 `#FAFAFA`，避免大面积高饱和色块。
- 中文标题上方可使用日语装饰小字；日语小字不承担唯一信息职责。

## 3. 线上登记页

### 3.1 页面结构

线上登记页为 `/` 的缺省页面，包含主题标题区、入场表单区和规则说明弹窗。

主题标题区：

- 日语小字「届かないメロディー」。
- 三行主题标题「旮旯原声之 / 届不到的 / BGM」。
- `BGM` 使用主色强调。
- 手机端标题字号使用 `clamp(48px, 17vw, 96px)`，页面不横向滚动。
- 标题区不显示多人同步、题目数量或无关玩法说明。

入场表单区：

- 引导词「准备入场」。
- 标题「先给自己起个名字」。
- 昵称说明「榜单会显示这个昵称。选一个容易辨认的名字。」
- 昵称输入框，最大 20 个字符。
- 主按钮「开始线上答题」。
- 状态提示「线上模式，无需等待主持人启动。开始后音频会自动播放。」
- 二维码提示「现场参与者请扫描主持人展示的二维码进入线下模式。」

### 3.2 规则弹窗

点击主按钮后显示规则弹窗。弹窗宽度为 `min(92vw, 520px)`，最大高度 88vh，内容可滚动。

规则条目：

1. **独立答题**：每位参与者在自己的设备上完成题库全部题目。
2. **连续音频**：点击开始后，完整音频连续播放；页面隐藏时音频暂停并保存进度。
3. **自动出题**：题目随音频时间自动上屏和锁定；当前题已选答案后可使用「下一题」按顺序提前推进，不提供任意题号跳转、回看或暂停。
4. **只显示总分**：全部题目结束后显示总分与已答数，不显示正确答案、作品名或逐题对错。
5. **重试与锁定**：结果页可选择重新作答或锁定成绩；锁定后成绩进入线上榜与总榜。

弹窗主按钮「我已了解，开始答题」。确认后调用线上加入接口并进入 `/play`。

### 3.3 本地恢复提示

浏览器存在可恢复进度时，主按钮显示「继续线上答题」，状态提示显示：

```text
已保存至第 x / N 题
上次保存：YYYY-MM-DD HH:mm
```

存在可恢复结果时，主按钮显示「查看上次成绩」。题集版本不一致时显示：

```text
题库已更新，请重新开始本次答题。
```

### 3.4 已锁定参与者

加入接口返回 `onlineLocked=true` 时：

- 主按钮显示「查看锁定成绩」。
- 页面显示线上分数、线上名次、总榜名次与锁定时间。
- 不提供重试入口。

### 3.5 异常

- 昵称为空：按钮禁用，不显示网络请求。
- 昵称超过 20 字：输入框阻止继续输入并显示字数提示。
- 网络失败：表单上方显示错误条，保留昵称与输入内容。
- 题库或音频不可用：显示「答题素材暂不可用」，禁用开始按钮。
- 未知模式参数：进入线上模式，并显示「模式参数无效，已进入线上模式」。

## 4. 线下登记页

### 4.1 入口

地址：`/?mode=offline`；`/offline?event={eventId}` 等价。

页面沿用主题标题与昵称表单，模式徽标显示「线下模式」。表单主按钮为「加入本轮」。

### 4.2 页面提示

- 状态行显示当前轮次加入状态：等待开始、可加入或本轮已结束。
- 说明文案「加入后等待主持人开始，题目会与现场音频同步上屏。」
- 规则弹窗说明逐题作答、锁卷、揭晓与本轮结算。
- 页面提供次级按钮「进入线上模式」，跳转到 `/?mode=online&event={eventId}`。

### 4.3 加入结果

- `WAITING` 或 `ANSWERING` 状态允许加入。
- `FINISHED` 状态显示「本轮已结束，请等待主持人切换下一轮」。
- 加入成功保存 `playerId` 并进入 `/play`。
- 线下登记页不显示线上排行榜、线上进度或线上重试入口。

### 4.4 昵称回填

昵称输入框优先读取 `localStorage` 的长期昵称，其次读取当前标签页昵称。轮次切换或活动重置返回登记页时自动回填。

## 5. 线上答题页

### 5.1 页头

页头包含：

- 活动名称。
- 「线上模式」徽标。
- 当前阶段说明。
- 退出入口。

退出前保存进度。退出不清除 `participantId`、昵称或本地进度。

### 5.2 开始前

无本地进度时显示：

- 题库总题数。
- 完整音频预计时长。
- 「音频开始后自动出题；已选答案后可进入下一题，不能任意跳题或回看」。
- 开始按钮「开始答题」。

有 `IN_PROGRESS` 本地进度时显示：

- 已保存题号。
- 已答与未答数量。
- 上次保存时间。
- 主按钮「继续答题」。

有 `RESULT_READY` 本地进度时直接进入结果页。

有服务端锁定记录时进入 `LOCKED` 结果页。

点击「开始答题」后，线上音频从第一题 `audioStartMs` 开始播放，母带为纯 BGM，不含开场播报。首题在 `answerStartMs` 上屏。

### 5.3 作答主界面

布局顺序：

1. 页头与线上模式徽标。
2. `OnlineProgress` 只读进度卡片。
3. 当前题卡片。
4. 音频状态与本题剩余时间。
5. 四个选项。
6. 作答提示与「下一题」按钮。

进度卡片：

- 标题行：左侧「第 x / N 题」，右侧「已答 a · 未答 b」与折叠控件。
- 标题行下方为线性总进度条，折叠状态下同样保持显示。
- 题号圆点网格：题号 1 至 N 依次排列，按容器宽度自动换行；桌面圆点 25px、间距 7px，手机圆点 24px、间距 6px。
- 圆点状态：已答使用 `--accent-light` 底色与 `--accent-dark` 文字；当前题使用 `--accent` 实心与白色文字；未到达为白底浅边框；已过期未答为虚线边框。全部不可点击，不提供任意跳题。

进度卡片折叠：

- 触发区域为整个标题行，鼠标点击与键盘 Enter、Space 均可切换。
- 展开态折叠控件显示「收起题号」与向上箭头；收起态显示「展开题号」与向下箭头；手机端隐藏文案，改为 26px 方形箭头按钮，可点热区 44×44px。
- 标题行在手机端保持单行：左侧题号，右侧「已答 / 未答」与箭头按钮，不因换行增加高度。
- 收起仅隐藏题号圆点网格，标题行、已答与未答数量、总进度条保留，卡片高度约为展开态的一半。
- 折叠状态仅在本次作答会话内保持，切换题目、音频推进与暂停遮罩均不改变折叠状态；重新进入页面默认展开，不写入本地存储。
- 折叠控件使用 `aria-expanded` 标记展开状态，并以 `aria-controls` 指向网格容器；折叠不影响任何作答数据。

当前题卡片：

- 题型标签「作品题」或「氛围题」。
- 难度标签「简单」「中等」或「困难」。
- 出题人署名「出题人：<署名>」。
- 题干。
- A、B、C、D 四个选项。
- 作答提示与「下一题」按钮。

选项状态：

| 状态 | 视觉与行为 |
| :--- | :--- |
| 未选择 | 白底、浅边框。 |
| 已选择 | 主色边框、`--accent-light` 底色。 |
| 当前题锁定 | 保持选择状态，全部选项禁用。 |
| 已进入后续题 | 当前题卡片被替换，不提供回看。 |

选项交互：

- 仅在当前题 `answerStartMs <= 音频位置 < answerEndMs` 时可点击。
- 允许在当前题窗口内修改选择。
- 到达 `answerEndMs` 后立即禁用。
- 不显示正确答案、错误配色、解析或作品名。

推进按钮：

- 位于当前题卡片底部操作区右侧，不属于进度卡片。
- 仅在当前题作答窗口开放、当前题已选答案且存在下一题时可用。
- 当前题未选答案时按钮保持可见并禁用；最后一题不渲染按钮。
- 点击后进入「音频定位中」加载状态，将音频定位到下一题 `answerStartMs`。
- 音频进入可播放状态后显示下一题、保存进度并继续播放；定位期间暂停有效计时。
- 定位完成后音频继续播放，不出现暂停遮罩、答案揭晓或额外确认层。
- 按钮仅按题集顺序前进一题，不提供上一题或任意题号跳转。

### 5.4 时间显示

- 本题剩余时间按 `answerEndMs - audioPositionMs` 计算。
- 剩余 5 秒以内时数字与进度条使用 `--danger`。
- 时间条只表达当前题作答窗口，不显示答案或得分。
- 音频缓冲期间保持已保存的音频位置，不自动推进题目，并暂停有效作答计时。

### 5.5 题间过渡

当前题 `answerEndMs` 到达、下一题 `answerStartMs` 尚未到达时：

- 显示「本题已结束，下一题即将开始」。
- 不显示上一题题干、选项或正确性。
- 进度仍停留在上一题，直到下一题窗口开始。
- 点击「下一题」时显示「音频定位中」，定位完成后再进入下一题作答窗口。

### 5.6 页面隐藏

页面进入后台时：

- 音频暂停。
- 全屏遮罩显示「答题已暂停，进度已保存」。

页面回到前台时：

- 继续保持暂停。
- 遮罩主按钮为「继续答题」。
- 用户点击后从保存的音频位置恢复。
- 隐藏期间不计入有效作答耗时。

### 5.7 不得出现的控件

线上答题页不出现：

- 上一题。
- 任意题号跳转列表。
- 音频暂停、播放、拖动、倍速或静音控件。
- 查看历史题目的入口。
- 答案揭晓或解析。
- 提前交卷与锁定按钮。

## 6. 线上结果页

### 6.1 预览结果

最后一题音频播放结束后，结果页显示：

- 大号总分。
- 已答题目数 / 总题目数。
- 有效作答耗时。
- 「重试」按钮。
- 「锁定分数」按钮。

提示文案：

```text
本次成绩尚未进入榜单。锁定后不可重试。
```

结果页不显示正确答案、作品名、解析、逐题对错或答案分布。

### 6.2 重试

点击「重试」显示确认层：

```text
重试会清空本次答案并重新播放全部音频，当前预览分不会入榜。
```

确认后：

- 删除本地进度与预览结果。
- 生成新 `attemptId`。
- 回到开始前状态。
- 用户点击「开始答题」后重新播放音频。

### 6.3 锁定

点击「锁定分数」显示确认层：

```text
锁定后本次分数进入线上榜与总榜，且不能重试。
```

确认后：

- 锁定按钮进入加载状态并禁用。
- 请求成功进入 `LOCKED`。
- 请求失败保留结果页、答案和预览分，显示错误并恢复按钮。
- 返回 `409` 时读取锁定状态；已有记录时进入 `LOCKED`。

### 6.4 锁定结果

锁定后显示：

- 总分。
- 线上积分榜名次。
- 总榜名次。
- 锁定时间。
- 排名说明「后续线下结算或线上锁定可能改变总榜名次」。
- 「返回登记页」按钮。

锁定结果页不显示「重试」。

### 6.5 预览失败

预览请求失败时：

- 保留本地答案与音频结束位置。
- 显示「分数暂未获取」。
- 提供「重新获取分数」。
- 不提供锁定按钮，直到预览成功。

### 6.6 锁定状态查询失败

进入线上页面时状态查询失败：

- 显示网络错误。
- 不自动开始新 attempt。
- 提供「重新连接」。
- 本地进度保持不变。

## 7. 线下答题页

### 7.1 页头

- 活动名称。
- 「线下模式」徽标。
- 当前轮次名称。
- 退出入口。

退出只结束当前标签页的线下会话，不删除 `participantId` 与长期昵称。

### 7.2 等待阶段

`status=WAITING` 时显示：

- 大号活动主题标题「旮旯原声之届不到的 BGM」。
- 状态「等待主持人开始」。
- 当前轮次名称。
- 联机状态指示。
- 已加入人数。

等待阶段不显示题目、选项或倒计时。参与者无需操作。

### 7.3 作答阶段

`status=ANSWERING` 时显示：

- 当前题号「第 x / N 题」。
- 题型与难度标签。
- 题干。
- 四个选项。
- 本题音频剩余时间条。
- 「确认答案」按钮。

选项规则：

- 点击选项只更新本地选中态，不立即提交。
- 点击「确认答案」调用线下提交接口。
- 提交成功后选项只读，显示「已提交 x，等待结果」。
- `canAnswer=false` 时显示「本题无法提交」。
- 重复提交由服务端拒绝，页面刷新快照后按服务端状态展示。

作答阶段不显示正确答案、解析、作品名、出题人或正确/错误配色。

### 7.4 锁卷阶段

`status=ANSWER_LOCKED` 时：

- 选项保持可见但全部只读。
- 状态文案「答题已结束，等待答案揭晓」。
- 已提交玩家显示自己的选项字母。
- 未提交玩家显示「本题未作答」。
- 不显示正确选项。

### 7.5 揭晓阶段

`status=ANSWER_REVEALED` 时：

- 正确选项使用 `--green` 边框与 `--green-soft` 底色。
- 玩家选中但错误的选项使用 `--danger` 边框与 `--danger-soft` 底色。
- 显示作品名。
- 显示出题人署名，格式为「出题人：<署名>」。
- 显示解析卡片。
- 显示玩家选择或「本题未作答」。

揭晓配色只用于线下逐题反馈。

### 7.6 本轮结算

`status=FINISHED` 时显示：

- 标题「本轮挑战完成」。
- 本轮得分。
- 本轮累计耗时。
- 本轮名次。
- 本轮榜列表。
- 榜单中的本人行使用主色浅底或主色边线强调。

榜单条目包含名次、昵称、得分与耗时。前三名徽章依次使用主色实体、主色中间阶与主色浅阶。

### 7.7 状态变化

- `ACTIVITY_STARTED`：刷新快照，进入等待或作答状态。
- `QUESTION_STARTED`：清空本地选中态并显示新题。
- `ANSWER_LOCKED`：禁用选项。
- `ANSWER_REVEALED`：显示正确选项、作品名、解析与出题人。
- `ACTIVITY_FINISHED`：读取本轮榜并显示结算。
- `ROUND_ENDED`：停止时间轴提示，不直接清空结算内容。
- `ACTIVITY_RESET`：清空线下玩家凭据并回到线下登记页。

### 7.8 剩余时间

- 本题时间条使用服务端 `questionAudioStartEpochMs` 与 `questionAudioEndEpochMs`。
- 时间轴运行时按墙上时刻更新。
- 暂停时冻结剩余时长。
- 恢复后按平移后的结束时刻继续。
- 剩余 5 秒以内使用警示色。

## 8. 主持人控制台

### 8.1 登录页

- 标题上方日语小字「管理者ログイン」。
- 中文标题「主持人登录」。
- 密码输入框。
- 主按钮「进入控制台」。
- 密码错误显示统一错误，不区分密码不存在或令牌失效。

登录成功后令牌保存在当前标签页 `sessionStorage`。

### 8.2 页头

控制台页头包含：

- 日语小字「進行管理」。
- 中文标题「现场控制台」。
- 当前活动名称。
- 在线人数。
- 状态徽标「等待开始」「答题中」「已锁卷」「答案揭晓」「本轮结束」。
- 重置活动按钮。

页头不显示参与者导航。

### 8.3 轮次与音频

轮次区域：

- 选择器展示轮次名称、`startMs` 至 `endMs` 与题目数量。
- 时间轴运行时禁用轮次切换。
- 切换轮次前显示确认，明确会清空在线玩家与答题记录。

播放控制：

- `WAITING` 且时间轴未运行时显示「开始播放」。
- 运行中显示「暂停」。
- 暂停中显示「恢复」。
- 「重置活动」始终可执行，执行前二次确认。
- 开始播放定位到当前轮次 `startMs`，用户手势触发音频播放，随后调用启动接口。
- 启动接口失败时立即暂停音频并显示错误。

音频看板：

- 当前轮次名称。
- 音频区间。
- 当前播放位置与进度条。
- 状态「待启动」「运行中」「已暂停」「已结束」。
- 缺失音频文件时显示素材错误，不显示伪造进度。
- 播放位置文本与进度条按不超过 4 次/秒的频率刷新，不随媒体元素的每次 `timeupdate` 重绘整个控制台。

实时事件处理：

- 广播到达时先同步执行音频控制，再触发快照刷新。音频控制使用广播携带的 `roundId`，不使用可能在快照返回后变化的当前轮次。
- 广播与 HTTP 快照携带活动状态版本号 `revision`。控制台保存已应用的最大版本号，丢弃版本号更小的广播与快照，避免旧轮次事件在新轮次开始后暂停或定位音频。
- WebSocket 重新连接时重置本地版本号基线并立即读取快照，适配服务端重启后版本号从头计数的情形。
- `ACTIVITY_PAUSED` 暂停音频；`ACTIVITY_RESUMED` 恢复播放；`ACTIVITY_FINISHED` 与 `ROUND_ENDED` 暂停音频并定位到事件所属轮次的 `endMs`。
- `PLAYER_ANSWERED`、`PLAYER_JOINED` 等高频广播在 200 毫秒窗口内合并为一次快照刷新。同一时刻最多存在一个快照请求，刷新期间到达的广播在当前请求完成后最多再触发一次刷新。
- `ONLINE_SCORE_LOCKED`、`ACTIVITY_FINISHED` 与 `ROUND_ENDED` 合并触发线上榜与总榜刷新，避免同一结算周期内重复读取榜单。

### 8.4 二维码

扫码区显示：

- 线下入口二维码。
- 地址文本 `/?mode=offline`，以链接形式展示，点击在新标签页打开线下登记页。
- 说明「参与者扫码后输入昵称加入本轮」。
- 复制地址按钮；安全剪贴板接口不可用时使用兼容回退完成复制，复制失败时控制台顶部提示错误，地址文本可选中并可直接点击打开。

二维码编码内容为线下入口路径与当前 `eventId`。域名来自当前页面的 `publicBaseUrl`。

### 8.5 题目与玩家

题目预览区：

- 当前题号与题目总数。
- 题型、难度与题干。
- 主持人可见的作品名与出题人。
- 揭晓后显示正确答案、作品名、解析与出题人。
- `LOAD` 完成、`NEXT` 未触发时显示「待上屏题目」。

玩家区：

- 在线人数。
- 已提交人数 / 在线人数。
- 玩家昵称列表。
- 当前题已提交标记。
- 当前题未提交标记。
- 本轮得分与耗时。

玩家作答状态按服务端快照刷新，不在广播到达时本地推断提交结果。

### 8.6 手动兜底

按钮与可用状态：

| 按钮 | 可用状态 |
| :--- | :--- |
| 锁卷 | `ANSWERING` |
| 揭晓答案 | `ANSWER_LOCKED` |
| 下一题 | 时间轴已启动，`WAITING` 或 `ANSWER_REVEALED`，且本轮存在下一题 |
| 结束本轮 | 时间轴已启动，当前题为本轮最后一题且处于 `ANSWER_REVEALED` |

按钮请求期间禁用。主持人快照提供 `canAdvanceQuestion` 与 `canFinishRound`，分别驱动「下一题」和「结束本轮」。揭晓答案与下一题预加载之间可立即手动推进；服务端直接读取本轮下一题，并取消该题尚未触发的自动预加载。最后一题揭晓后由「结束本轮」替代「下一题」。结束本轮后控制台提供四个轮次的选择器与「开启下一轮」操作；选择器默认指向时间轴顺序中紧邻的下一轮，末轮结束后回到第一轮。主持人对选择器的更改在状态刷新期间保持不变，选择器仅在结束轮次发生变更时重新取默认值。「开启下一轮」以所选轮次重置房间，并从该轮 `startMs` 起播。服务端返回状态守卫错误时，在控制台页头下方显示错误并刷新快照；动作成功后立即应用响应状态并刷新快照。

「下一题」将主持人音频定位到新题 `audioStartMs`。时间轴运行时定位完成后继续播放；时间轴暂停时保持暂停。主持人快照中的 `audioPositionMs` 表示当前时间轴对应的音频毫秒位置，用于动作完成后的播放器校准。

主持人动作接口返回的 `EventState.revision` 立即写入本地已应用版本号。动作完成后触发的快照刷新保留更高版本号的数据；版本号更低的在途响应被丢弃。

线上最后一题已选择答案且音频仍在播放时显示「结束答题」。操作暂停音频、将 attempt 状态设为 `RESULT_READY` 并请求预览分；该状态使用与音频自然播放结束相同的结果页与重试、锁定入口。

### 8.7 榜单区域

榜单区域使用三个页签：

#### 本轮榜

- 来源 `GET /leaderboard`。
- 只在 `FINISHED` 时显示数据。
- 展示名次、昵称、得分、耗时。
- 用于现场评奖。

#### 线上榜

- 来源 `GET /leaderboards/online`。
- 展示名次、昵称、得分、已答数、耗时、锁定时间。
- 线上成绩不进入本轮榜。
- 收到 `ONLINE_SCORE_LOCKED` 后刷新。

#### 总榜

- 来源 `GET /leaderboards/total`。
- 展示名次、昵称、总分、线下分、线上分、总耗时、线下轮次数与线上锁定标记。
- 可展开线下各轮贡献明细。
- 收到 `ONLINE_SCORE_LOCKED`、`ACTIVITY_FINISHED` 后刷新。

榜单为空时显示「暂无成绩」。榜单请求失败时保留上一份成功数据并显示刷新错误。

### 8.8 文本总结

主持人区域提供「查看文本总结」与「下载文本总结」：

- 链接指向 `GET /api/events/{eventId}/leaderboard/summary-txt`。
- 在线查看使用等宽字体。
- 下载文件名为 `leaderboard_summary.txt`。
- 文本包含线下轮次榜、线上积分榜与总榜。

### 8.9 控制台适配

手机端：

- 页头、轮次控制、音频看板、二维码、题目、玩家与榜单单列堆叠。
- 主操作按钮全宽。
- 榜单表格允许横向滚动，昵称列保持可读。

宽屏端：

- 左侧显示轮次、音频、二维码。
- 右侧显示题目、玩家与榜单。
- 控制区与榜单区保持独立滚动。

## 9. 通用状态与提示

### 9.1 加载

网络连接异常，请检查网络后重试。

以下操作使用确认层：

- 切换线下轮次。
- 重置线下活动。
- 线上重试。
- 线上锁定分数。

确认层说明后果与是否可撤销。线上锁定、切换轮次与重置活动均不可在页面内撤销。

## 10. 文案规范

- 主要标题、状态、操作、错误提示与规则说明使用中文。
- 日语小字只作为标题装饰，不承担唯一信息。
- 不使用英文装饰眉题。
- 活动主题标题统一为「旮旯原声之届不到的 BGM」。
- 线上模式文案明确「无需等待主持人」「自动出题」「不显示答案」。
- 线下模式文案明确「等待主持人」「逐题揭晓」「本轮榜用于评奖」。
- 分数单位使用「分」，耗时使用「秒」或时分秒格式。
- 不把总分榜与线下轮次榜混称为同一榜单。

## 11. 无障碍与交互

- 所有按钮与选项可通过键盘聚焦和触发。
- 选项采用原生按钮或具备等价语义的元素。
- 当前题变化时更新页面标题与无障碍提示。
- 倒计时不作为唯一状态信号，同时显示文字。
- 已选、已答、锁定与当前题同时使用文字、边框或形状差异。
- 触控目标不小于 44×44px。
- 错误提示与状态变化使用 `aria-live` 区域播报。
- 动画尊重 `prefers-reduced-motion`。

## 12. 页面验收

### 12.1 线上

- 根地址显示线上登记页与「开始线上答题」。
- 规则弹窗说明全部题目、连续音频、自动推进、只显示总分、重试与锁定。
- 答题页显示只读进度，不出现任意跳题、回看、暂停与拖动。
- 进度卡片标题行可收起题号网格；收起后题号隐藏，进度条、剩余时间与作答区不受影响，再次点击恢复展开。
- 当前题已选答案时「下一题」可用；未选答案时禁用，最后一题不显示「下一题」，已选答案且音频仍在播放时显示「结束答题」。
- 点击「下一题」后显示定位状态，音频定位到下一题 `answerStartMs` 并进入可播放状态后显示下一题。
- 点击「下一题」后刷新页面可从下一题保存位置继续。
- 当前题关闭后不可修改。
- 页面隐藏后音频暂停，返回需要点击继续。
- 结果页只显示分数、已答数与耗时，不显示答案。
- 重试生成新 attempt 且不入榜。
- 锁定后显示线上名次与总榜名次，不显示重试。

### 12.2 线下

- 线下二维码进入线下登记页。
- 登记页提供「进入线上模式」。
- 等待、作答、锁卷、揭晓与结算按服务端状态切换。
- 答题阶段不泄露答案。
- 揭晓阶段显示正确选项、作品名、解析与出题人。
- 结算显示本轮榜。

### 12.3 主持人

- 登录后可选择轮次并开始播放。
- 音频、时间轴与手动动作状态一致。
- 二维码指向线下入口 `/offline`。
- 榜单可在本轮榜、线上榜与总榜之间切换。
- 线上锁定后线上榜与总榜自动刷新。
- 文本总结可在线查看与下载。
