# 活动规则、编排梯度与竞速算法

## 1. 活动基本规范
- **活动场景**：社团招新摊位现场实时互动，参与者扫码加入同一轮次进行同步答题。
- **音源形式**：一个完整音频文件由主持人控制台连接现场音箱统一播放，各轮次为音频内的连续区段；题目上屏、作答窗口与揭晓时机全部由编排文件定义。
- **轮次规模**：单轮题目数量与运行时长由编排决定，建议单轮布置 6 道单项选择题、整体运行耗时约 3~4 分钟。
- **轮次循环**：编排文件定义多个轮次，到达轮次结束标记时间轴自动暂停，主持人切换轮次后接待下一批参与者。
- **奖品原则**：每位参与者仅限兑换一次奖品，奖品数量有限，先到先得。

## 2. 编排结构与难度梯度

题目包含两种分类：
- **作品题 (`WORK`)**：根据现场背景音识别出对应的作品名称。
- **氛围题 (`ATMOSPHERE`)**：根据现场背景音判断其最适配的游戏场景氛围（如“温馨日常”、“悬疑推理”、“激战决斗”等）。

难度梯度在编排制作时建议按以下配比安排单轮题目：

| 难度等级 | 建议数量 | 题型定位 | 辨析特征 |
| :--- | :--- | :--- | :--- |
| **简单 (EASY)** | 3 道 | 经典作品核心主题或高辨识度日常旋律 | 旋律流传度广，未接触过原作品亦可通过曲风判断 |
| **中等 (MEDIUM)** | 2 道 | 特色配乐或场景特定情绪曲目 | 旋律具备鲜明氛围感，需结合乐器编排与节奏进行推断 |
| **困难 (HARD)** | 1 道 | 小众经典或结构复杂的场景背景音乐 | 考验参与者的音乐阅历与细微曲风捕捉能力 |

## 3. 计分与竞速仲裁算法

### 3.1 得分规则
- 单题作答正确得 10 分，单轮满分为 10 分 × 该轮题目数。
- 单题作答错误，或锁卷时仍未提交得 0 分。
- 系统不设固定作答时限，作答通道由编排中的锁卷动作关闭。

### 3.2 耗时统计逻辑
- **单题有效耗时**：参与者提交时刻与本题上屏时刻的毫秒差值 $\Delta t$。
- **缺席补记**：锁卷时尚未提交的玩家，按“锁卷时刻 − max(本题上屏时刻, 加入时刻)”补记该题耗时。
- **中途加入**：玩家加入后即可参与作答并进入排行榜；加入前已锁卷的题目不产生耗时记录。
- **累计总耗时**：单轮所有题目耗时之和为参与者的总作答耗时（`totalDurationMs`）。

### 3.3 排名仲裁优先级
排行榜按以下三级排序规则依次仲裁：
1. **第一优先级（最终得分）**：按得分从高到低排序（`score DESC`）。
2. **第二优先级（总耗时竞速）**：得分相同时，按累计总耗时从短到长排序（`totalDurationMs ASC`），用时短者排在前面。
3. **第三优先级（加入时间）**：得分与总耗时均相同时，按加入活动的先后顺序排序（`joinedAt ASC`）。

## 4. 全场大总结与去重奖品榜

系统在每轮结算时维护两张榜单：
1. **全场总排行榜**：汇集活动期间所有轮次的所有玩家答题记录，展示跨轮次竞技总排行。
2. **个人最佳成绩总榜（奖品发放参考）**：依据“每人限制参与一次”的活动规则，系统对玩家昵称进行去重归并，仅保留每位独立昵称玩家在各轮次中产生的单轮最高得分（同分取耗时最短记录）参与全场排名，作为现场礼品兑现的唯一核销参考。
