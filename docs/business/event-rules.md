# 活动规则、计分与榜单

## 1. 活动基本规范

- **活动场景**：社团活动现场互动与线上独立答题并行。
- **音源形式**：线上与线下各用一段完整音频。线上为纯 BGM 母带，由参与者设备连续播放全部题目音频；线下为含播报母带，由主持人控制轮次区间播放，每轮起点包含开幕播报段。
- **题库范围**：线上覆盖 `questions.json` 全部题目；线下按主持人选中的轮次运行。
- **轮次规模**：线下单轮题目数量与运行时长由编排决定；线上题目总数等于线上题集长度。
- **模式入口**：网页默认线上；现场二维码通过 `/offline` 进入线下，`?mode=offline` 查询参数等效。
- **奖品原则**：线下轮次榜用于现场评奖；线上积分榜用于线上成绩；总榜用于跨模式累计展示。

## 2. 题目分类与难度

题目包含两种分类：

- **作品题 (`WORK`)**：根据音频识别作品名称。
- **氛围题 (`ATMOSPHERE`)**：根据音频判断场景氛围。

难度等级：

- `EASY`：简单。
- `MEDIUM`：中等。
- `HARD`：困难。

线下单轮难度配比由编排制作决定。线上按 `timeline-online.json` 的题目顺序拉平，不按难度重新分组；该文件缺省时取 `timeline.json`。

## 3. 计分规则

- 答对按题目难度计分：简单题 2 分，中等题 3 分，困难题 5 分。
- 答错得 0 分。
- 未作答得 0 分。
- 线上总分 = 全部答对题目的难度分之和。
- 线下单轮得分 = 本轮答对题目的难度分之和。
- 结果页显示答错题数与计分规则；答错题数统计已提交且错误的题目，不包含未作答题目。

## 4. 线上模式规则

### 4.1 答题流程

1. 参与者进入 `/`，输入昵称。
2. 浏览器获取线上题集与音频地址。
3. 参与者点击「开始答题」或「继续答题」。
4. 音频从第一题起连续播放，题目按 `audioStartMs` 上屏、`answerEndMs` 关闭作答；参与者可点击题号或「上一题」「下一题」切换题目，也可拖动当前题进度条与重播本题。
5. 不显示正确答案、作品名或逐题对错；解析作为提示随题展示。
6. 全部题目结束后，服务端计算预览分。
7. 结果页提供「重试」与「锁定分数」。

### 4.2 线上推进规则

- 线上不使用轮次，不显示轮次名称。
- 题目按线上题集顺序出现。
- 当前题作答窗口开放时，题号、上一题与下一题均可切换题目；切换时音频定位到目标题 `audioStartMs`，并保持切换前的播放或暂停状态。
- 当前题进度条可拖动，重播本题定位到当前题 `audioStartMs` 并继续播放。
- 最后一题提供「结束答题」，可将 attempt 置为结果预览状态。
- 未操作切题控件时，音频继续播放并按时间标记自动推进。
- 当前题锁定前可以修改选项。
- 页面隐藏或关闭时暂停音频并保存进度；返回后从保存位置继续。
- 未答题目按 0 分。

### 4.3 进度控件

- 显示「第 x / N 题」。
- 显示总进度条。
- 显示已答与未答数量。
- 题目序号圆点可点击，并切换到对应题目。
- 上一题、下一题与题号切换均位于当前题卡片或进度控件内，不额外弹出确认层。
- 切换题目时若音频正在播放则继续播放，暂停则保持暂停。

### 4.4 重试

- 仅在全部题目结束并显示预览分后可用。
- 清空浏览器本地进度与预览分。
- 生成新的 `attemptId`。
- 从第一题重新开始。
- 不写入线上榜。

### 4.5 锁定

- 仅在全部题目结束并显示预览分后可用。
- 服务端根据提交答案重新计算分数。
- 每个 `participantId` 只保留一条线上锁定记录。
- 同一 `attemptId` 重复锁定返回已有结果。
- 不同 `attemptId` 在已锁定后再次锁定返回冲突。
- 锁定成功后显示线上榜名次与总榜名次。
- 锁定后不提供重试入口。

### 4.6 线上本地进度

- 当前题号、已选答案、音频位置、剩余作答时间保存在浏览器本地。
- 选择或修改答案、点击「下一题」、题目自动锁定与页面隐藏时立即保存进度。
- 服务端不保存进行中的线上 attempt。
- 本地进度按 `eventId`、`participantId` 与 `questionSetVersion` 校验。
- 题库或时间轴变化导致题集版本变化时，旧进度失效。
- 清除浏览器站点数据、换浏览器或换设备会丢失本地进度。

## 5. 线下模式规则

### 5.1 轮次与音频

- 主持人选择轮次并点击开始播放。
- 音频从 `round.startMs` 播放，到达 `round.endMs` 停止本轮播放。
- 服务端按编排自动上屏、锁卷、揭晓与结算。
- 轮次切换清空在线玩家并回到 `WAITING`。

### 5.2 作答与揭晓

- `NEXT` 上屏当前题、下发提示与出题人并开放作答。
- `LOCK` 关闭作答，不公布正确答案与作品名。
- `REVEAL` 公布正确答案与作品名。
- `FINISH` 结算本轮并生成线下榜。
- 参与者可在 `LOCK` 前修改选项并提交。
- 锁卷时未提交的玩家按参与时长补记耗时。

### 5.3 线下耗时

- 单题有效耗时 = 提交时刻 − 本题 `NEXT` 时刻。
- 锁卷时未提交玩家按“锁卷时刻 − max(本题 NEXT 时刻, 加入时刻)”补记。
- 加入前已锁卷的题目不产生耗时记录。
- 本轮累计耗时为各题耗时之和。

## 6. 榜单结构

### 6.1 线下榜

- 每个线下轮次在 `FINISH` 时生成独立榜单。
- 排序：得分降序，累计耗时升序，加入时间升序，昵称升序。
- 线下榜用于现场评奖。
- 线下榜不包含线上锁定成绩。

### 6.2 线上积分榜

- 每个 `participantId` 一条线上锁定记录。
- 排序：得分降序，有效作答耗时升序，锁定时间升序，昵称升序。
- 线上榜只包含线上锁定成绩。
- 线上成绩不写入线下榜。

### 6.3 总榜

总榜由两部分组成：

1. 线下部分：按 `participantId` 分组，每个线下轮次取最佳一次成绩；同分取耗时更短的一次；跨轮次求和。
2. 线上部分：该 `participantId` 的线上锁定成绩，最多一条。

总榜排序：

1. 总分降序。
2. 累计耗时升序。
3. 最后活动时间升序。
4. 昵称升序。

线上锁定成功后返回该参与者当前总榜名次。总榜名次随后续线下结算或线上锁定变化；页面刷新后展示最新名次。

## 7. 身份与合并

- 线上与线下共用 `participantId`，保存在浏览器 `localStorage`。
- 线下每次加入生成独立 `playerId`，用于轮次内玩家会话。
- 线上每次尝试生成独立 `attemptId`，用于预览与锁定幂等。
- 总榜按 `participantId` 合并线上与线下成绩。
- 历史线下记录缺少 `participantId` 时以 `playerId` 作为合并键。
- 昵称用于展示，不作为唯一合并键。

## 8. 评奖与核销

- 现场评奖以线下轮次榜为准。
- 线上积分榜用于线上成绩核对。
- 总榜用于跨模式累计展示。
- 每位参与者仅限兑换一次奖品，奖品数量有限，先到先得。
- 核销时核对昵称、线下轮次榜名次与总榜记录。

完整流程、接口与验收标准见 [`../product/dual-mode-development-spec.md`](../product/dual-mode-development-spec.md)。
