# 现场多岗位协同 SOP

## 1. 岗位职责与分工矩阵

| 岗位名称 | 配备人数 | 核心设备 | 核心工作职责 |
| :--- | :--- | :--- | :--- |
| **主场控** | 1 人 | 控制台笔记本电脑、现场音箱 | 选择与切换轮次，播放音频，监控时间轴运行，实施应急操作 |
| **秩序引导** | 1~2 人 | 二维码展示牌/展示平板 | 引导现场同学扫描线下二维码、登记昵称并维持秩序 |
| **奖品核销** | 1 人 | 奖品库、登记册、核销章 | 校验线下轮次榜、线上积分榜与总榜，发放奖品并完成实名盖章 |

## 2. 现场标准作业流程

### 2.1 轮次准备与召集

1. **选择轮次**：主持人在控制台轮次选择器中选定本轮要运行的轮次；选择操作自动重置房间并清空上一批在线玩家，系统进入 `WAITING` 就绪状态。
2. **扫码入场**：秩序引导员展示线下二维码，组织参与者扫码进入 `/offline?event=demo` 并输入昵称。
3. **人数核对**：主持人观察控制台在线玩家列表，确认参与人数达到本轮预期后，准备启动。

### 2.2 轮次运行与音频协同

1. **开始播放**：主持人点击控制台「开始播放」，音频从当前轮次 `startMs` 起播，时间轴零点同步建立。
2. **自动推进**：系统按编排依次执行预加载、题目上屏、锁卷与揭晓；控制台实时展示音频进度与时间轴状态。
3. **作答监控**：主持人观察作答进度监控墙的「已作答人数 / 在线总人数」，掌握现场节奏。
4. **轮次暂停**：到达轮次结束标记时，时间轴与音频自动暂停，控制台提示可切换轮次或重置。

### 2.3 活动结算与奖品兑现

1. **自动结算**：编排中的 `FINISH` 动作触发结算，系统持久化本轮线下榜，手机端同步展示总得分、总耗时与本轮名次。
2. **现场核销**：
   - 获奖参与者出示手机结算界面。
   - 奖品核销人员核对参与者昵称与控制台本轮榜成绩。
   - 需要跨轮次核对时，查看控制台「总榜」或 `leaderboard_summary.txt`。
   - 发放对应奖品，并在参与者手背盖章登记，防止重复领奖。
3. **接待下一批**：主持人切换轮次后，参与者由答题页返回登记页，昵称自动回填，可快速重新加入。

## 3. 线上模式协同

- 线上模式由参与者独立开始，不需要主持人启动轮次或播放音频。
- 线上参与者通过网页默认入口 `/` 进入，按浏览器播放的完整音频自动答题。
- 线上全部题目结束后显示预览分；参与者选择「重试」或「锁定分数」。
- 锁定成功后，成绩进入线上积分榜与总榜；结果页显示线上榜名次与总榜名次。
- 主持人控制台可切换「本轮榜 / 线上榜 / 总榜」查看线上锁定情况。
- 线上锁定触发 `ONLINE_SCORE_LOCKED` 广播后，控制台刷新线上榜与总榜。

## 4. 榜单使用规则

| 榜单 | 数据来源 | 使用场景 |
| :--- | :--- | :--- |
| 线下轮次榜 | 每个线下轮次 `FINISH` 快照 | 现场评奖与核销。 |
| 线上积分榜 | 线上锁定记录 | 线上成绩核对与展示。 |
| 总榜 | 线下各轮最佳成绩 + 线上锁定成绩 | 跨模式累计展示。 |

线上成绩不写入线下轮次榜。总榜名次随后续线下结算或线上锁定变化；页面刷新后展示最新名次。

## 5. 现场应急处置机制

1. **音频节奏失误（音量异常、播放被打断）**：
   - 主持人立即点击控制台「暂停」按钮，时间轴与音频同步冻结。
   - 排除问题后点击「恢复」，系统按剩余时长继续推进，无需重排编排。
2. **需要提前推进或提前公布**：
   - 全员已提前完成提交时，主持人可点击「锁卷」「揭晓答案」「下一题」实施快速推进；被手动满足语义的时间轴条目在触发时自动跳过。
3. **临时网络抖动导致手机端离线**：
   - 引导参与者下拉刷新页面，系统根据本地缓存的凭据自动恢复线下房间状态。
4. **线上参与者本地进度丢失**：
   - 清除浏览器数据、换浏览器或换设备会丢失线上本地进度；参与者可从第一题重新开始。
   - 已锁定成绩保存在服务端，不因本地进度丢失而消失。
5. **线上锁定请求失败**：
   - 保留本地答案与预览结果，点击「锁定分数」再次提交；服务端按 `attemptId` 幂等处理。
