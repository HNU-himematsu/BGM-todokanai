# 现场多岗位协同 SOP

## 1. 岗位职责与分工矩阵

| 岗位名称 | 配备人数 | 核心设备 | 核心工作职责 |
| :--- | :--- | :--- | :--- |
| **主场控** | 1 人 | 控制台笔记本电脑、现场音箱 | 选择与切换轮次，播放音频，监控时间轴运行，实施应急操作 |
| **秩序引导** | 1~2 人 | 二维码展示牌/展示平板 | 引导展台同学扫码登记，维持作答区域现场秩序 |
| **奖品核销** | 1 人 | 奖品库、登记册、核销章 | 校验同学结算成绩与去重总榜，发放奖品并完成实名盖章 |

## 2. 现场标准作业流程 (SOP)

### 2.1 轮次准备与召集
1. **选择轮次**：主持人在控制台轮次选择器中选定本轮要运行的轮次；选择操作自动重置房间并清空上一批在线玩家，系统进入 `WAITING` 就绪状态。
2. **扫码入场**：秩序引导员展示二维码，组织 5~15 名同学扫码进入网页并输入昵称。
3. **人数核对**：主持人观察控制台在线玩家列表，确认参与人数达到本轮预期后，准备启动。

### 2.2 轮次运行与音频协同
1. **开始播放**：主持人点击控制台「开始播放」，音频从当前轮次开始标记起播，时间轴零点同步建立。
2. **自动推进**：系统按编排依次执行预加载、题目上屏、锁卷与揭晓各动作；控制台实时展示音频进度与时间轴状态。
3. **作答监控**：主持人观察作答进度监控墙的「已作答人数 / 在线总人数」，掌握现场节奏。
4. **轮次暂停**：到达轮次结束标记时，时间轴与音频自动暂停，控制台提示可切换轮次或重置。

### 2.3 活动结算与奖品兑现
1. **自动结算**：编排中的 `FINISH` 动作触发结算，系统持久化本轮榜单，手机端同步展示总得分、总耗时与本轮名次。
2. **现场核销**：
   - 获奖参与者出示手机结算界面。
   - 奖品核销人员核对参与者昵称与控制台最终成绩，或查阅 `leaderboard_summary.txt` 中的去重最佳成绩榜。
   - 发放对应奖品，并在参与者手背盖章登记，防止重复领奖。
3. **接待下一批**：主持人切换轮次后，参与者由答题页返回登记页，昵称自动回填，可快速重新加入。

## 3. 现场应急处置机制

1. **音频节奏失误（音量异常、播放被打断）**：
   - 主持人立即点击控制台「暂停」按钮，时间轴与音频同步冻结。
   - 排除问题后点击「恢复」，系统按剩余时长继续推进，无需重排编排。
2. **需要提前推进或提前公布**：
   - 全员已提前完成提交时，主持人可点击「锁卷」「揭晓答案」「下一题」实施快速推进；被手动满足语义的时间轴条目在触发时自动跳过。
3. **临时网络抖动导致手机端离线**：
   - 引导参与者下拉刷新页面，系统根据本地缓存的凭据自动重新恢复房间状态。
