# 排行榜持久化存储与解析

## 1. 持久化存储体系

系统由两个持久化文件构成榜单存储体系：
- **原始快照 JSON**：`backend/data/leaderboards.json`
- **格式化大总结 TXT**：`backend/data/leaderboard_summary.txt`

## 2. 原始快照数据结构 (`leaderboards.json`)

每当活动轮次进入 `FINISHED` 状态时，服务端将向 JSON 数组追加一个轮次快照对象：

```json
[
  {
    "eventId": "demo",
    "eventName": "旮旯原声之届不到的 BGM",
    "finishedAt": "2026-10-06T13:06:12.128Z",
    "entries": [
      {
        "rank": 1,
        "playerId": "131da7ba-09b9-4253-9f00-9773d062527a",
        "nickname": "01",
        "score": 10,
        "durationMs": 87100
      },
      {
        "rank": 2,
        "playerId": "04acb893-40e8-4c85-a291-68ef91662a74",
        "nickname": "02",
        "score": 0,
        "durationMs": 85200
      }
    ]
  }
]
```

### 字段说明
- `eventId`：活动唯一标识。
- `finishedAt`：轮次结束的标准 ISO-8601 UTC 时间戳。
- `entries[].rank`：该轮内根据得分与竞速总耗时综合计算的最终名次。
- `entries[].durationMs`：该参与者全轮累计作答耗时（毫秒数），锁卷时未提交的题目按参与时长补记计入。

## 3. 格式化大总结与去重榜 (`leaderboard_summary.txt`)

该文本由 `LeaderboardStore.java` 自动输出，亦可通过 `parse_leaderboard.py` 离线输出。包含两大核心板块：

### 3.1 全场总排行榜
汇总活动至今全部轮次参与者记录，统一按 `得分 DESC -> 耗时 ASC -> 轮次时间 ASC` 排列。

### 3.2 个人最佳成绩总榜（奖品发放参考）
根据活动“每人限制领奖一次”的要求，按参与者昵称去重，仅提取每位昵称名下的单轮最高分（同分取最低耗时），明确标出该成绩产生的轮次与累计参与次数。

```text
========================================================================================================================
【个人最佳成绩总榜 · 奖品发放参考（按昵称去重，共 3 人）】
规则说明: 依据“每人限制参与一次，奖品先到先得”，多次参与者仅取其单轮最佳成绩参与最终排名
------------------------------------------------------------------------------------------------------------------------
总排名     玩家昵称           最高得分   对应耗时       产生轮次     参与次数         玩家ID
------------------------------------------------------------------------------------------------------------------------
第 1 名    01                 10 分      0.0 秒         第 1 轮      共参与 2 轮      8f716f5d-b27d-4f8a-9366-866786989c05
第 2 名    爱丽莎             0 分       0.0 秒         第 1 轮      共参与 1 轮      03161ec7-112d-4401-8081-aec7185fa264
第 3 名    02                 0 分       0.0 秒         第 1 轮      共参与 2 轮      ef0b709f-e9ce-49ed-a6d2-91d9358c1c81
========================================================================================================================
```

## 4. 离线 Python 工具 (`parse_leaderboard.py`)

在无需启动 Java 服务的环境下，使用 Python 直接解析生成或刷新文本榜单：

```bash
# 在项目根目录下执行
python parse_leaderboard.py
```

- 脚本自动定位并解析 `backend/data/leaderboards.json`。
- 采用与 Java 端相同的双字节中文字符宽度计算算法，确保在 Windows 记事本等纯文本编辑器中呈现等宽对齐排版。
