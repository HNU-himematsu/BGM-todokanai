题库与编排录入模板

一、总则

1. 题库与编排由运营方按本模板整理，开发与后端校验以同一份内容为准。
2. 题库文件为 questions.json，编排文件为 timeline.json，二者与完整音频放在同一目录。
3. 全部题库题目必须被 timeline.json 中至少一个 LOAD 条目引用。
4. 线上题集按轮次和条目顺序拉平并去重；线下按主持人选中的轮次运行。
5. 完整音频包含全部题目内容，题目片段之间不留空白。
6. 第一题音频从 00:00.000 开始，最后一题的音频结束时间对齐完整音频结束时间。
7. 时间使用“分:秒.毫秒”填写，例如 01:23.450；写入 JSON 时换算为毫秒整数。
8. 同一轮次内各动作时间严格递增。
9. 一轮中每道题按 LOAD、NEXT、LOCK、REVEAL 顺序出现，轮次末尾出现 FINISH。
10. 题目编号全局唯一，选项固定四项，正确答案填写 A、B、C 或 D。

二、字段填写说明

轮次：

- 轮次名称：现场展示名称，例如“第一轮”。
- 轮次开始：本轮音频起点。
- 轮次结束：本轮音频终点；到达后时间轴与音频暂停。
- 轮次区间互不重叠，可以首尾相接。

题目：

- 题目编号：使用 Q-01、Q-02 等唯一编号；JSON 中可使用同一字符串。
- 音频编号：素材核对编号，使用 TRACK-01、TRACK-02 等。
- 题目音频片段开始：本题音乐在完整音频中的起点。
- 题目音频片段结束：本题音乐在完整音频中的终点；下一题的片段起点与本值相同。
- LOAD：题目预加载时刻，早于或等于 NEXT。
- NEXT：题目上屏并开放作答的时刻。
- LOCK：关闭作答的时刻。
- REVEAL：公布正确答案、作品名与出题人的时刻，晚于 LOCK。
- 题干：参与者看到的题目文本。
- 题型：ATMOSPHERE 或 WORK。
- 难度：EASY、MEDIUM 或 HARD。
- 选项 A 至 D：四项候选文字。
- 正确答案：A、B、C 或 D。
- 作品名：音乐来源作品；线上不下发，线下揭晓时展示。
- 解析：线下题目上屏后作为提示展示的文本；线上不下发。
- 题目作者：出题人署名；线下揭晓、主持人控制台与线上答题页展示。

时间关系：

    audioStart <= NEXT < LOCK <= audioEnd

下一题约束：

    上一题 audioEnd == 下一题 audioStart

六、提交前检查

1. 题目编号无重复。
2. 所有题目均被 timeline.json 引用。
3. 每道题四个选项，正确答案下标为 0 至 3。
4. 每个题目片段都有 LOAD、NEXT、LOCK、REVEAL。
5. 每轮都有 FINISH。
6. NEXT 不早于题目音频起点，LOCK 不晚于题目音频终点。
7. 相邻题目音频片段无空白。
8. 第一段从 0 开始，最后一段结束于完整音频末尾。
9. 题型、难度、正确答案与作品名已复核。
10. 完整音频、题库与编排三者使用同一套时间。
